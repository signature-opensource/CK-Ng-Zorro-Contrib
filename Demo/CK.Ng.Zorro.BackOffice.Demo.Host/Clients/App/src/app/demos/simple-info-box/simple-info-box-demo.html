The ck-simple-info-box component displays a label/value pair in a styled box. Useful for dashboards and summary panels. Supports an optional icon with color accent.

API

InputTypeRequiredDescription
label string Yes The label displayed above the value.
value string | number Yes The value to display.
icon IconDefinition No FontAwesome icon shown in a tinted circle on the left.
color string No CSS color for the icon and its background tint. Defaults to primary color.
subtitle string No Secondary text displayed below the value.
