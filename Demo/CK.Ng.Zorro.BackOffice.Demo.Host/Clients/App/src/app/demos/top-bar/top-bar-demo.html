The ck-backoffice-top-bar component renders the top navigation bar. It is already visible at the top of this application. It is configured through the parent ck-backoffice-layout component.

Features

  • User info — displays the user name and a profile/disconnect menu
  • WCS dropdown — optional Working Context Selector dropdown
  • Theme toggle — optional dark/light theme toggle button
  • Notification icon — optional notification bell icon
  • Language selector — language switching support

Inputs (via Layout)

InputTypeDefaultDescription
[userName]string''User name displayed in the top bar.
[displayThemeToggle]booleanfalseShow the theme toggle button.
[displayWCSDropdown]booleanfalseShow the WCS dropdown.
[displayNotifIcon]booleanfalseShow the notification bell.
[selectedLanguage]string'fr'Currently selected language code.
[selectedWCS]string | WCSType-Currently selected WCS value.
[allWCS]Array<string | WCSType>-All available WCS options.

Outputs

OutputTypeDescription
(themeToggled)voidTheme toggle button clicked.
(profileClicked)voidProfile menu item clicked.
(disconnectClicked)voidDisconnect menu item clicked.
(wcsSelected)string | WCSTypeWCS selection changed.
(notificationClicked)voidNotification bell clicked.
