The ck-backoffice-layout-content component wraps page content with a header (title + breadcrumb), action bar, and filter panel. This page itself uses it — you can see the header title, filter button, and action bar above.

Live configuration

Inputs

InputTypeDefaultDescription
[headerTitle]string''Page title displayed in the header.
[showFilters]booleantrueShow the filter toggle button.
[filters]Array<Filter>[]Filter definitions for the filter panel.
[actions]ActionBarContent<T>emptyAction bar configuration.
[selectedItems]Array<T>[]Selected items passed to action bar.
[breadcrumb]Array<BreadcrumbItem>[]Breadcrumb navigation items.
[breadcrumbSeparator]string'>'Separator between breadcrumb items.

Outputs

OutputTypeDescription
(filtersApplied)Array<Filter>Filters were applied.
(filtersCleared)voidFilters were cleared.
(breadcrumbItemClicked)BreadcrumbItemA breadcrumb item was clicked.
