The ck-selectable-list component renders a list of items with selection support. It supports single-select and multi-select modes, custom item templates, and two-way binding via [(selectedItems)].

API

PropertyTypeDefaultDescription
[items] Array<T> required The data items to display.
[itemUniqueKey] keyof T required Property name used to uniquely identify items.
[itemTemplateRef] TemplateRef required Template for rendering each item. Context: $implicit: T, selected: boolean.
[multiSelect] boolean false Allow selecting multiple items.
[(selectedItems)] Array<T> [] Two-way bound selected items.
(selectionChanged) Array<T> - Emitted when the selection changes.
(itemDblClicked) T - Emitted on double-click of an item.
