The ck-adaptive-page-layout component provides a responsive page layout that automatically switches between a table view (desktop) and a list view (mobile). It integrates filters, search, actions, and pagination.

Resize your browser to see it switch between table and list modes.

Key features

  • Automatic table/list switching based on viewport width
  • Integrated search with debounce
  • Filter support (SwitchFilter, SelectFilter)
  • Action bar with context-aware buttons
  • Pagination with configurable page size
  • Custom item template for list view mode
