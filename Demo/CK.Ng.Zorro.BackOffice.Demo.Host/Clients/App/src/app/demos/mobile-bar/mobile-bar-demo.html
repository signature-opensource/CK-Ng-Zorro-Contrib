The ck-backoffice-mobile-bar component provides bottom navigation on mobile viewports. It is part of the ck-backoffice-layout and is only visible on narrow screens.

Resize your browser window to a mobile width to see the mobile bar appear at the bottom.

Features

  • Appears automatically on mobile-width viewports
  • Shares the same navigationItems as the sidebar
  • Provides search, profile, and notification access
  • Optional WCS dropdown

Inputs (via Layout)

InputTypeDefaultDescription
[navigationItems]Array<NavigationSection>[]Same navigation items as the sidebar.
[displayNotifIcon]booleanfalseShow notification bell.
[searchPlaceholder]string''Search input placeholder.
[selectedWCS]string | WCSType-Currently selected WCS.
[allWCS]Array<string | WCSType>-Available WCS options.

Outputs

OutputTypeDescription
(searchRequested)stringSearch query submitted.
(wcsSelected)string | WCSTypeWCS selection changed.
(profileClicked)voidProfile button clicked.
(notificationClicked)voidNotification bell clicked.
