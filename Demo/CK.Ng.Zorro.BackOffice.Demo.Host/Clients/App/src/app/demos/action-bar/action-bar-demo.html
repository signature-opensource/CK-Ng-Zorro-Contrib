The ck-action-bar component displays a toolbar with left and right action groups. Each action can have an icon, danger style, and conditional visibility/disabled state. It is embedded in ck-backoffice-layout-content but can also be used standalone.

Interactive demo

Simulate selection: Toggle to show/hide "Edit" and "Delete" actions (right side)

Features

  • Left / Right groups — actions are split into two alignment groups
  • Icons — each action can have a FontAwesome IconDefinition
  • Danger style — isDanger: true renders the button in red
  • Conditional visibility — shouldBeDisplayed callback controls visibility
  • Conditional disabled — shouldBeDisabled callback controls disabled state

API

InputTypeDescription
[actions] ActionBarContent<T> Object with left and right arrays of action definitions.
[selectedItems] Array<T> Currently selected items (passed to action callbacks).
