The ck-backoffice-breadcrumb component displays breadcrumb navigation. It supports icons, click handlers, and truncation via minItemsShow.

API

InputTypeDefaultDescription
[breadcrumbItems] Array<BreadcrumbItem> [] Breadcrumb items to display.
[separator] IconDefinition faChevronRight Icon used as separator between items.
[minItemsShow] number - If set, truncates to show only this many items (first + last).
(navItemClicked) BreadcrumbItem - Emitted when a breadcrumb item is clicked.

BreadcrumbItem model

PropertyTypeDescription
namestringDisplay text.
iconIconDefinitionOptional FontAwesome icon.
onClick() => voidOptional click handler.
disabledbooleanDisable the item.
childrenArray<BreadcrumbItem>Nested items.
