The ck-loader component displays a full-overlay loading spinner. When [isLoading] is false, the host element is hidden (display: none) so it does not block interaction. Place it inside a container with position: relative to scope the overlay.

Toggle loader

isLoading: {{ isLoading }}

Content area

This content sits behind the loader overlay. When loading is active, the spinner appears on top.

Click the button above to toggle the loading state.

Usage

<div style="position: relative">
  <ck-loader [isLoading]="isLoading()" />
  <!-- your content -->
</div>

API

InputTypeDefaultDescription
isLoading boolean false When true, shows the overlay and spinner. When false, the host is display: none.
