The ck-generic-form component dynamically builds a form from a configuration object. It supports field types: text, number, date, password, select, and checkbox. Validation, error messages, and conditional visibility are all declarative.

All field types

@if (formSubmitted) {
Form submitted!
}

Configuration

Create a GenericFormData object with a dictionary of FormControlConfig instances. Each config defines the field type, label, default value, validators, and error messages.

Field typeDescription
textStandard text input
numberNumeric input
passwordPassword input (masked)
dateDate picker
selectDropdown select (single/multiple/tags)
checkboxBoolean checkbox

API

InputTypeDescription
[inputFormData] GenericFormData Form configuration with field definitions.
[formLayout] 'horizontal' | 'vertical' | 'inline' Form layout direction (default: 'vertical').
(submitRequested) void Emitted on Enter key press (when not in modal).
