CK.Ng.Zorro provides three filter types: SwitchFilter (boolean toggle), SelectFilter (single/multi select dropdown), and DateRangeFilter (date range picker with optional presets). Filters are managed as an array and displayed via ck-backoffice-layout-content or the standalone ck-filters component.

Use the filter button in the page header above to toggle and apply filters.
