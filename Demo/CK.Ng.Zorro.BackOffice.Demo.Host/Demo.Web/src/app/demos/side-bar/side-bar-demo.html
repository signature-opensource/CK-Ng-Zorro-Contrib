The ck-backoffice-side-bar component renders the collapsible sidebar navigation. It is visible on the left side of this application. Configuration is done through the parent ck-backoffice-layout.

Features

  • Logo — displayed at the top of the sidebar
  • Navigation sections — grouped navigation items with headlines
  • Nested items — items can have children (accordion-style)
  • Icons — each item can have a FontAwesome icon
  • Active state — automatically highlights the current route
  • Collapsible — sidebar can collapse to icons-only mode
  • Global search — optional search button that opens the search modal
  • Version info — optional version display in the footer

NavigationSection model

The sidebar is configured with an array of NavigationSection objects:

PropertyTypeDescription
sectionHeadlinestringSection header text (empty for no header).
itemsArray<NavigationItem>Navigation items in this section.
bottombooleanIf true, section is pinned to the bottom.

NavigationItem model

PropertyTypeDescription
labelstringDisplay text for the item.
routerLinkstringAngular router link (optional).
iconIconDefinitionFontAwesome icon (optional).
childrenArray<NavigationItem>Nested child items (optional).
isActivebooleanForce active state (optional).
disabledbooleanDisable the item (optional).

Example configuration

navSections = [
  {
    sectionHeadline: 'Basic',
    bottom: false,
    items: [
      { label: 'Table', routerLink: 'basic/table', icon: faTable },
      { label: 'ListView', routerLink: 'basic/list-view', icon: faList },
    ]
  }
];
