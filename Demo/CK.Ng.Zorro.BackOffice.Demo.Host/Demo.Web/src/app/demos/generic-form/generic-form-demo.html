The ck-generic-form component renders a signal form built from field definitions. It supports field types: text, number, date, password, select, checkbox and custom. Validation rules carry their messages, and conditional visibility is declarative.

Configuration

Call genericForm( () => fields ) once in the owning component with a dictionary of field definitions built by the field factories. Each definition holds the label, default value, placeholder and signal-form rules, each rule carrying its message (required( p, {{ '{' }} message: 'Key' {{ '}' }} )). Labels, placeholders, option labels and messages are translation keys; a text that is not a key shows as written. Cross-field rules go in genericForm( ..., {{ '{' }} rules {{ '}' }} ): an error a rule puts on a field shows under that field, and an error on the form itself shows at the top of the form.

API

InputTypeDescription
[form] GenericFormHandle The handle returned by genericForm(). Without it, as modal content, the form is built from nzData: {{ '{' }} fields, rules? {{ '}' }} and read from handle().
[formLayout] 'horizontal' | 'vertical' | 'inline' Form layout direction (default: 'vertical').
[appearance] 'labelled' | 'compact' Labels with messages under the controls (default), or no labels, large inputs and error tips.
[errorDisplay] 'text' | 'tip' Messages under the control (default) or as error tips; compact always uses tips.
(submitRequested) void Emitted on Enter typed inside the form (when not in modal).
