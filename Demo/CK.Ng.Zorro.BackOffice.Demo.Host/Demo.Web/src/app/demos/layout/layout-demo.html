The ck-backoffice-layout component is the main application shell. It composes the SideBar, TopBar, and MobileBar into a responsive layout. You are currently inside one — it wraps this entire application.

Structure

ck-backoffice-layout
SideBar
TopBar
<router-outlet />
MobileBar (mobile only)

Inputs

InputTypeDefaultDescription
[navigationItems]Array<NavigationSection>[]Sidebar navigation sections and items.
[userName]string''User name displayed in the top bar.
[logoSrc]stringDefault logoPath to the sidebar logo image.
[displayThemeToggle]booleanfalseShow the theme toggle button in the top bar.
[displayWCSDropdown]booleanfalseShow the WCS (Working Context Selector) dropdown.
[displayNotifIcon]booleanfalseShow the notification bell icon.
[showGlobalSearchBtn]booleanfalseShow the global search button in the sidebar.
[globalSearchPlaceholder]string''Placeholder for the global search input.
[globalSearchDebounceTime]number300Debounce time for global search (ms).
[defaultContentTpl]TemplateRef-Default content template for the search modal.
[searchResultTpl]TemplateRef-Search results template for the search modal.
[selectedLanguage]string'fr'Currently selected language.
[versionInfos]VersionInfos-Version information shown in the sidebar footer.

Outputs

OutputTypeDescription
(logoClicked)voidLogo in the sidebar was clicked.
(themeToggled)voidTheme toggle button was clicked.
(languageChanged)stringLanguage selection changed.
(profileClicked)voidProfile button was clicked.
(disconnectClicked)voidDisconnect button was clicked.
(globalSearchRequested)stringGlobal search query submitted.
(globalSearchCleared)voidGlobal search cleared.
(navItemClicked)NavigationItemA navigation item was clicked.
(navbarCollapsedChanged)booleanSidebar collapse state changed.
