The ck-split-view component provides a master-detail layout. It projects two content areas: a sidebar (master) and a detail pane. On narrow viewports, the detail pane overlays the sidebar. Use [(detailVisible)] for two-way binding.

Master-detail layout

Click an item in the sidebar to see its details. Resize the browser to see the responsive behavior.
