The ck-inline-edit component provides click-to-edit (or double-click-to-edit) text input. It supports two-way binding via [(value)] and emits confirmed and cancelled events.

API

PropertyTypeDefaultDescription
[(value)] string '' Two-way bound text value.
[placeholder] string '' Placeholder text shown when value is empty.
[editOnDblClick] boolean false If true, requires double-click to enter edit mode.
(confirmed) string - Emitted when the edit is confirmed (Enter or blur).
(cancelled) void - Emitted when the edit is cancelled (Escape).
