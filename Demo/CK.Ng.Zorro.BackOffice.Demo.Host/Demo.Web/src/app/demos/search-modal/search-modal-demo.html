The ck-search-modal component provides a full-screen search modal with debounced input. It is integrated into the ck-backoffice-layout via the sidebar's search button.

Click the search icon in the sidebar (magnifying glass) to open the search modal and see it in action.

How it works

  • Triggered by the sidebar search button (when [showGlobalSearchBtn]="true")
  • Opens as a full-screen overlay with a search input
  • Search is debounced (configurable via globalSearchDebounceTime)
  • Supports a defaultContentTpl shown before any search is made
  • Supports a searchResultTpl shown after a search query

Configuration (via Layout)

InputTypeDefaultDescription
[showGlobalSearchBtn]booleanfalseShow the search button in the sidebar.
[globalSearchPlaceholder]string''Placeholder text for the search input.
[globalSearchDebounceTime]number300Debounce time in ms.
[defaultContentTpl]TemplateRef-Template shown when no search has been made.
[searchResultTpl]TemplateRef-Template shown with search results.

Outputs (via Layout)

OutputTypeDescription
(globalSearchRequested)stringSearch query submitted.
(globalSearchCleared)voidSearch input cleared.

Example template usage

<ck-backoffice-layout
  [showGlobalSearchBtn]="true"
  [globalSearchDebounceTime]="300"
  [globalSearchPlaceholder]="'Search...'"
  [defaultContentTpl]="defaultTpl"
  [searchResultTpl]="resultTpl"
  (globalSearchRequested)="onSearch($event)"
  (globalSearchCleared)="onClear()">
</ck-backoffice-layout>
<ng-template #defaultTpl>Recent items...</ng-template>
<ng-template #resultTpl>Search results...</ng-template>
