The layout of a back-office Angular application built on ng-zorro-antd: a side bar, a top bar, a mobile bar, a global
search and the content area of the pages.

The `ZorroBackOfficePackage` brings the `LayoutComponent` (with the `SideBarComponent`, the `TopBarComponent` and the
`MobileBarComponent`), the `LayoutContentComponent` (the breadcrumb, the filters and the action bar of a page) and the
`SearchModalComponent`. It uses CK.Ng.Zorro.Basic and CK.Ng.Zorro.Breadcrumb.
