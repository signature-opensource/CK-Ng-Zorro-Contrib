Optional ng-zorro-antd components for Angular applications: tables, lists, filters, forms and page layouts.

The components are the `TableComponent`, `ListViewComponent`, `SelectableListComponent`, `FiltersComponent`,
`ActionBarComponent`, `AdaptivePageLayoutComponent`, `GenericFormComponent`, `InlineEditComponent`,
`SplitViewComponent`, `SimpleInfoBoxComponent`, `BlockquoteComponent` and `LoaderComponent`, in the package of
CK.Ng.Zorro.
